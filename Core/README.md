# Документация по TaskManagementSystem::Core

В данном файле находится необходимая информация 💎, советы 📎 и руководство 📒 по использованию
**<span style="color: yellow;">Core</span>** библиотеки.

## Описание

Библиотека **<span style="color: yellow;">Core</span>** 📒 предоставляет базовые классы для работы модулей. На данный
момент она используется модулем **<span style="color: green;">API</span>** и
**<span style="color: green;">Auth</span>**; в следующих версиях может быть использована ✅ в других модулях для
взаимодействия 🤝 микросервисов между собой.

## Структура

Библиотека **<span style="color: yellow;">Core</span>** 📒 предоставляет **5** базовых пакетов классов **Java**:

* **<span style="color: blue;">dto</span>** 📨: DTO-классы для взаимодействия микросервисов между собой.
* **<span style="color: green;">entity</span>** 💡: Удобные классы для работы с сущностями.
* **<span style="color: orange;">exception</span>** 💥: Вспомогательные классы, помогающие работать с исключениями.
* **<span style="color: purple;">service</span>** 🚀: Некоторые вспомогательные классы для работы с сервисами.
* **<span style="color: red;">util</span>** 📎: Утилитные классы, которые помимо прочего помогают работать с
  фильтрацией.

Каждый можно подробно 📚 изучить непосредственно в коде.

## Сборка

Для сборки 🔨 необходимо выполнить следующие действия:

```shell

# Клонируем репозиторий
git clone https://github.com/a-slelin/TaskManagement.git;

# Переходим в папку Core;
cd TaskManagement/Core;

# Собираем jar-файл;
# Он будет находится по пути target/Core.jar;
mvn clean package;

# Или если хотите, можно установить библиотеку в локальный репозиторий maven (.m2);
mnv clean install;
```

Если вы хотите включить **<span style="color: yellow;">Core</span>** 📒 библиотеку в свой проект это можно сделать
подключив зависимость в файле **<span style="color: blue;">pom.xml</span>** вашего проекта в секции 📗 **dependencies**:

```xml

<dependecies>
    <!--
    Блок ваших зависимостей
    -->

    <dependency>
        <groupId>a.slelin.work.task.management</groupId>
        <artifactId>core</artifactId>
        <version>1.0</version>
    </dependency>

    <!--
    Блок ваших зависимостей
    -->
</dependecies>
```
