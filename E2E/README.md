# Документация по TaskManagementSystem::E2E

В данном файле находится необходимая информация 💎, советы 📎 и руководство 📒 по использованию
**<span style="color: orange;">E2E</span>** 📏 тестовых классов.

## Описание

**<span style="color: orange;">E2E</span>** 📏 модуль предоставляет автоматизированные тесты для приложения управления
задач. Тесты запускают под собой 🐳 docker-образы. Модуль скорей предназначен для разработчиков 👨‍💻 и тестировщиков.

## Структура

Тест-кейсы делятся по классам: каждый класс проверяет взаимодействие микросервисов только тех, что указаны в имени его
класса. Название теста формируется так:

```js
"Модуль 1" + "Модуль 2" + "..." + "Interaction" + "IT"
```

Например, название класса для проверки взаимодействия микросервисов **<span style="color: green;">Auth</span>** и
**<span style="color: green;">API</span>** будет:

```java
public class AuthApiInteractionIT {
}
```

Каждый класс с тестами можно подробно 📚 изучить непосредственно в коде.

## Запуск

Для запуска 🚀 тестов необходимо выполнить следующие действия:

```shell

# Запустите docker, если он у вас ещё не запущен;
# Клонируем репозиторий;
git clone https://github.com/a-slelin/TaskManagement.git;

# Переходим в папку Core;
cd TaskManagement/Core;

# Запускаем тесты;
mvn clean verify;

# Или можно так;
mnv clean test-compile failsafe:integration-test;
```

Если же хотите запустить конкретный класс и/или конкретный метод:

```shell

# Запускаем конкретный класс и метод;
mvn clean verify '-Dit.test=<Название класса>#<Название метода>';

# Или так;
mvn clean test-compile '-Dit.test=<Название класса>#<Название метода>' failsafe:integration-test
```
