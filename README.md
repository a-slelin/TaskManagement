# Система управления задачами 📑 и уведомлениями 📨

## <span style="color: orange;">Цели</span> 🎯

Целью репозитория 💎 **<span style="color: green;">TaskManagement</span>** 💎 является построение качественного приложения
🤳, которое помогает пользователям совместно работать над задачами и управлять своим графиком 📅. Система использует
современные технологии 🔧, чтобы достичь заявленных целей. Репозиторий является полностью открытым и может
использоваться в любых целях 💯.

Второстепенной целью проекта является развитие 📈 приложения от использования низкоуровневых технологий 🤔 вроде
сервлетов, до высокоуровневых технологий ✅, которые активно используются в наше время (Spring 🍃).

## <span style="color: brown;">Описание</span> 📎

Условные пользователи 🧒 (консоль, HTTP-клиенты и т.д.) взаимодействую с
**<span style="color: green;">Auth</span>**-микросервисом; в нём они могут регистрироваться, логиниться 🔐 и выходить
из системы. Также есть возможность управлять своими данными (телефон 📱, электронная почта 📧 и т.д.). После получения
токенов от **<span style="color: green;">Auth</span>**-микросервиса можно обращаться к
**<span style="color: green;">API</span>**-микросервису для того, чтобы работать со своими проектами и задачами 📝.
Также **<span style="color: green;">Auth</span>**-модуль предоставляет API для работы администраторов (роли, сессии
и т.д.).

Модули используют под собой общую библиотеку - **<span style="color: yellow;">Core</span>**. На изображении 🎨 ниже
показаны текущая верхнеуровневая схема работы приложения:

![Текущая верхнеуровневая схема приложения](images/CurrentUpperLevelSchema.svg)

## <span style="color: yellow;">Структура</span> 📁

Проект состоит из **4** основных модулей:

* **<span style="color: green;">API</span>** 🚀 - API для работы приложения с проектами и задачами.
* **<span style="color: green;">Auth</span>** 🔐 - API для работы приложения с пользователями, ролями и сессиями.
  Отвечает за jwt-токены.
* **<span style="color: yellow;">Core</span>** 📒 - Корневая библиотека для остальных модулей.
* **<span style="color: orange;">E2E</span>** 📏 - Тесты приложения.

Вы можете посетить каждый модуль 📚 и прочитать подробную информацию о том, как он работает.

## <span style="color: purple;">Требования</span> 📌

**1)** Приложение написано на языке **<span style="color: yellow;">Java</span>**. Используется последняя на данный
момент **<span style="color: yellow;">LTS</span>**-версия 📜 **<span style="color: yellow;">JDK</span>** -
**<span style="color: green;">25</span>**. В качестве **<span style="color: yellow;">IDE</span>** при разработке
использовалась 🤖 **<span style="color: yellow;">IntelliJ IDEA Community Edition</span>** (2026.1.1). Также, стоит
учесть, что большая часть приложения использует фреймворки **<span style="color: green;">Spring Framework 7</span>**
(7.0.7) 🍃 и **<span style="color: green;">Spring Boot 4</span>** (4.0.6) 🍃. Также используются сторонние библиотеки,
с которыми подробно можно ознакомиться в файле [**pom.xml**](pom.xml).

**2)** Для сборки 🔨 приложений используется **<span style="color: green;">Apache Maven</span>** (3.9.9).

**3)** Для хранения информации используется СУБД 🐘 **<span style="color: green;">Postgres</span>** (18.3).

**4)** Также используется 🐳 **<span style="color: green;">Docker</span>** (29.4.0).

## <span style="color: blue;">Запуск</span> 🚀

Для того чтобы запустить приложение, необходимо следовать инструкциям 📚, приведённым для каждого модуля в отдельности:

**1)** Запустить **<span style="color: green;">API</span>**-микросервис;

**2)** Запустить **<span style="color: green;">Auth</span>**-микросервис.

## <span style="color: yellow;">Релизы</span> 🏷

* **<span style="color: yellow;">v1.0</span>** 🔖 - создание простого низкоуровневого веб-приложения 💡.
* **<span style="color: yellow;">v2.0</span>** 🔖 - добавление 🔌 **JPA** (Hibernate), а также **Validation API**
  (Hibernate Validator).
* **<span style="color: yellow;">v3.0</span>** 🔖 - добавление **JAX-RS** (Jersey) 🔝.
* **<span style="color: yellow;">v4.0</span>** 🔖 - добавление полной совместимости с **Jakarta EE** 📖
  (деплой на WildFly).
* **<span style="color: yellow;">v5.0</span>** 🔖 - переход с **Jakarta EE** 📖 на **Spring Framework** 🍃.
* **<span style="color: yellow;">v6.0</span>** 🔖 - переход на **Spring Boot Framework** 🍃.
* Текущая версия **<span style="color: green;">v6.1</span>** 🔖 - переход на микросервисную 💎 архитектуру. Добавление
  модуля аутентификации 🔒.

### <span style="color: green;">Улучшения</span> ✅

**1)** Приложение было переведено на лад микросервисной 💎 архитектуры. Была выделена отдельная корневая библиотека
**<span style="color: yellow;">Core</span>** 📒.

**2)** Добавлен модуль (микросервис) **<span style="color: green;">Auth</span>**, который отвечают за безопасность 🔒
приложения: **<span style="color: green;">API</span>**-микросервис защищён и требует аутентификации 🔑 и авторизации.

**3)** Хранение информации о пользователях 🧒 перенесено на модуль **<span style="color: green;">Auth</span>**.

**4)** В **<span style="color: green;">Auth</span>**-модуле добавлен API для работы администраторов 👨‍💻 системы.

**5)** Был создан **<span style="color: orange;">E2E</span>**-модуль для автоматизации тестирования 📊 приложения в
целом.

### <span style="color: red;">Проблемы</span> ❌

**1)** Необходимо создать **<span style="color: yellow;">WebClient</span>**, который будет предоставлять версию
приложения для работы пользователей через браузеры 💻. Данный микросервис должен независимо общаться с
**<span style="color: green;">API</span>**-микросервисом. В качестве технологий можно добавить
**<span style="color: green;">thymeleaf, html, css, js</span>** 🚀.

**2)** Данная модель может быть улучшена для варианта, где пользователи могут приглашать 🤳 других пользователей в свои
проекты с разными ролями (чтение, изменение и т.д.) и т.п.

**3)** Необходимо рассмотреть возможность использования **<span style="color: yellow;">Discovery</span>**-микросервиса,
для обнаружения 🔎 того, где и кто запущен.

**4)** Также необходимо рассмотреть возможность внедрения
**<span style="color: yellow;">API Gateway</span>**-микросервиса для единой точки ⛔ входа в приложение.

**5)** Необходимо создать сервис, который будет уведомлять 📨 пользователей (и не только в перспективе) о неких
событиях, вроде приглашения и т.п. Данный ⏰ **<span style="color: yellow;">Notificator</span>**-микросервис слушает
данные из **<span style="color: green;">Apache Kafka</span>** 📩, куда их шлёт (не блокируясь)
**<span style="color: green;">API</span>**-микросервис.

**6)** Для увеличения производительности 📈 **<span style="color: green;">API</span>**-микросервиса необходимо
разработать кеширование в виде **<span style="color: green;">Redis</span>** 💡.

На данный момент проект стремится к реализации микросервисной архитектуры, верхнеуровневая схема которого выглядит так:

![Верхнеуровневая схема](images/UpperLevelSchema.svg)
